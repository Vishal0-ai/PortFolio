# Data Science Portfolio

A minimal, editorial-style portfolio inspired by the reference design.

## Files

- `index.html` — portfolio structure and content
- `style.css` — responsive styling
- `script.js` — mobile navigation, year and scroll reveal
- `Data.pdf` — add your own resume PDF here

## Run locally

1. Put all files in the same folder.
2. Add your resume as `Data.pdf`.
3. Open `index.html` in a browser.

For the best development experience, use VS Code + Live Server.
