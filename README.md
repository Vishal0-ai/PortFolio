# Data Science Portfolio

A minimal, editorial-style portfolio inspired by the reference design.

## Files

- `index.html` — portfolio structure and content
- `style.css` — responsive styling
- `script.js` — mobile navigation, year and scroll reveal
- `resume.pdf` — add your own resume PDF here

## Run locally

1. Put all files in the same folder.
2. Add your resume as `resume.pdf`.
3. Open `index.html` in a browser.

For the best development experience, use VS Code + Live Server.

## Customize

Search for:

- `[Your Name]`
- `your.email@example.com`
- GitHub links (`href="#"`)
- LinkedIn links (`href="#"`)
- Project names/descriptions
- Skills
- Journey/timeline entries

No framework is required.
